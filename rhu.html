SMS Server (Semaphore API)

SMS is sent via the Semaphore gateway — covers all PH networks (Globe, Smart, Sun, DITO) at ~₱0.50–0.56/SMS.

Step 1: Sign up free at semaphore.co and copy your API key.

Step 2: Edit server/.env and set SEMAPHORE_API_KEY (and optionally a registered SEMAPHORE_SENDER_NAME).

Step 3: Run cd server && npm install && node server.js

Step 4: Confirm SMS_SERVER_URL in config.js points at the running server.
